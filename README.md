# ESP32 Sonar — MicroPython + Radar Display

## Файлы

| Файл | Назначение |
|------|-----------|
| `main.py` | MicroPython для ESP32 (если нужна своя прошивка) |
| `radar_app.py` | Десктопное радарное приложение (Python 3) |
| `requirements.txt` | Зависимости Python |

---

## Запуск радарного приложения

### 1. Установите зависимости (один раз)

```bash
pip install -r requirements.txt
```

### 2. Запустите приложение

```bash
python radar_app.py
```

### 3. В приложении

- Выберите COM-порт из выпадающего списка (или нажмите ⟳ для обновления)
- Нажмите **Подключить**
- Радар начнёт отображать данные в реальном времени

---

## Формат данных (ожидаемый от устройства)

Приложение понимает строки в формате:
```
HH:MM:SS.mmm -> дистанция  115.2  угол
```
Например:
```
14:26:28.790 -> 48.29897  115.2  0
14:26:29.228 -> 47.92096  115.2  4
```

- **дистанция** — расстояние до объекта (первое число)
- **115.2** — константа (максимальная дальность, используется для масштаба)
- **угол** — текущий угол сервопривода в градусах

Временну́ю метку (`14:26:28.790 -> `) приложение отсекает автоматически.

## Подключение HC-SR04 (если прошиваете сами)

```
HC-SR04      ESP32 DevKit
VCC    →     5V
GND    →     GND
TRIG   →     GPIO5
ECHO   →     GPIO18  ⚠️ через делитель напряжения (5V→3.3V)
```

Делитель для ECHO:
```
ECHO → R1(1кОм) → GPIO18
                    ↓
               R2(2кОм)
                    ↓
                   GND
```

## Настройки приложения (в начале radar_app.py)

```python
BAUD_RATE    = 115200   # скорость Serial
MAX_DISTANCE = 115.2    # максимальная дальность (для масштаба радара)
SWEEP_STEPS  = 58       # количество шагов развёртки
ANGLE_STEP   = 2        # шаг угла в градусах
FADE_STEPS   = 30       # длина шлейфа точек
```
